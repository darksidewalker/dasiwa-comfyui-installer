Quick Install
=============
Single binary, zero dependencies. Download, run, done.

Download
--------
Put the binary in the folder where you want the installer state to live.

Linux:

    curl -L -o dasiwa-installer-linux-amd64 \
      https://raw.githubusercontent.com/darksidewalker/dasiwa-comfyui-installer/main/dasiwa-installer-linux-amd64
    chmod +x dasiwa-installer-linux-amd64

Windows (PowerShell):

    $u='https://raw.githubusercontent.com/darksidewalker/dasiwa-comfyui-installer/main/dasiwa-installer-windows-amd64.exe'
    $o='dasiwa-installer-windows-amd64.exe'
    if (Get-Command curl.exe -ErrorAction SilentlyContinue) {
        curl.exe -fL --retry 5 --retry-delay 2 -o $o $u
    } else {
        Start-BitsTransfer -Source $u -Destination $o
    }

Run
---
Linux:     ./dasiwa-installer-linux-amd64
Windows:   double-click dasiwa-installer-windows-amd64.exe

What happens
------------
The app opens a local browser page and runs the native Go install engine.
Everything -- UI, config, assets, README, license -- is embedded in the
binary. No Python, no pip, no config.json, no cloned repo needed.

On first run it creates a local .dasiwa/ directory for uv, the managed Python
runtime, and cache files. All ComfyUI packages stay inside ComfyUI/venv/.
